# 测试环境说明
本测试环境用于学员进行大赛试题内容开发和临时测试程序开发结果的环境，不作为最终大赛评审运行环境，最终大赛评审采用统一的集群环境。
## Linux环境
本测试环境包内包含一个基于**VirtualBox**的**Linux**虚拟机，**CentOS7**系统，**x86**架构，已内置了一些主流的类库，开发人员使用过程中缺少相关依赖库可自行安装。  
请尽量使用本测试包里的虚拟机进行开发，如使用个人机器预制的Linux系统开发，请确保**系统版本**和**CPU架构**与虚拟机**完全一致**，以免最终评审测试时因系统或架构不兼容导致出现的一些程序运行异常问题。
### 虚拟机使用说明
请参阅**虚拟机使用说明.txt**文档

## Windows环境
Windows开发可使用个人微机开发，操作系统要求为**64位Windows 10**，**x86架构**
