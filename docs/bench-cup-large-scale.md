## 数据生成方式

使用项目自带 `gen_fast_data` 工具，与Cup官方生成器相同算法：
- `std::mt19937` + `std::uniform_real_distribution<float>(0.0, 1.0)`
- 按X-Y-Z顺序写入（Z最快变化）
- 无文件头，纯float32

### 维度计算方法

容量主曲线使用统一比例 `Nx : Ny : Nz ≈ 2 : 2.2 : 3`：
- `Nx × Ny × Nz × 4 ≈ 目标字节数`
- 非对齐边界：`Nx = 32k + 1`, `Ny = 32m + 9`, `Nz = 32n + 23`
