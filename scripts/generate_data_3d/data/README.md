## 1. 通用说明
数据包包含两个三维数据集，均取自真实三维叠后地震数据，分别命名为**small.dat**和**big.dat**。 
数据文件存放的全部是数据样点，不含数据头、数据元信息等信息。  
数据文件中数据样点均为顺序存放，存放顺序为X-Y-Z的顺序，即先存放同一X值同一Y值的不同刻度的Z值，紧接着存同一X下一Y值的所有Z值，按这样的顺序依次将三维数据转成一维数据存储； 
如X范围为x1->x(m), y范围为y1->y(n),Z范围为z1->z(t),其存储顺序可示意如下：

> x1(y1(z1, z2, ..., zt), y2(z1, z2, ..., zt), ... , yn(z1, z2, ... , zt)), x2(y1(z1, z2, ..., zt), y2(z1, z2, ..., zt), ... , yn(z1, z2, ... , zt)), ... , xm(y1(z1, z2, ..., zt), y2(z1, z2, ..., zt), ... , yn(z1, z2, ... , zt))   

数据文件中的数据样点均为32位单精度浮点数（float）,占四个字节，数据文件大小等于总样点数x浮点数字节长度
